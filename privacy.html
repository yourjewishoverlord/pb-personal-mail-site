Privacy policy

This policy covers pb-personal-mail, a private tool used only by its owner with the owner's own Google accounts. Last updated: 25 November 2026.

What the tool accesses

With the owner's consent the tool uses the Gmail API (scope gmail.modify) to read messages and their labels, to add and remove labels, to mark messages as read and to create drafts in the owner's own mailboxes. It does not permanently delete mail.

How the data is used

Mailbox data is used for one purpose: to give the owner a summary of new mail, to sort it with labels and to prepare reply drafts for the owner to review. A message is sent only when the owner explicitly approves it. The data is not used for advertising and is not sold.

Storage and sharing

The tool has no server of its own. Access tokens are kept in the owner's own credential store and in the private settings of the environment where the owner runs the tool. Mailbox content is processed by the owner's own scripts and by an AI assistant service that the owner uses under their own account to produce the summaries and drafts. It is not shared with any other person or organisation. Summaries are visible only to the owner.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time on the Google account page Third-party apps and services. After that the tool can no longer read or change the mailbox.

Contact

Questions about this policy can be raised as an issue in the public repository that hosts this page.
