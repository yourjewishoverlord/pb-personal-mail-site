pb-personal-mail

pb-personal-mail is a private tool with one user: its owner. It connects to the owner's own Gmail mailboxes through the Gmail API so that scripts the owner runs can read new mail, apply labels, prepare reply drafts and build a short summary of what came in.

The tool is not a public service. It is not offered to other people, has no sign-up and no shared server. If you reached this page from a Google sign-in screen and you are not the owner, there is nothing here for you to use, and you should not grant access.

What the tool does with mailbox data is described in the privacy policy.
